# Logo concepts

The shipping app icon is `../AppIcon.svg` (based on `01-midnight-ivory.svg`).

| File | Palette | Notes |
| --- | --- | --- |
| `01-midnight-ivory.svg` | deep navy/plum + warm ivory | shipping version, most restrained |
| `02-cobalt-coral.svg` | cobalt + ivory + coral base | stronger emphasis on the connected base |
| `03-porcelain-ink.svg` | warm porcelain + ink + terracotta base | light icon variant |
| `04-cobalt-ivory.svg` | cobalt + ivory, no accent bar | cleanest two-color version |

The P counter is filled with the icon background, not transparent. Tray icon
sources live in `../tray-*.svg`.
